## Machine Learning for Beta Source Deconvolution in Liquid Scintillation Counting

Python 3.9.12. Numpy 1.22.4, scipy 1.14.1, scikit-learn 1.4.2, matplotlib 3.9.2, pandas 2.1.1, openpyxl 3.1.5, tqdm 4.64.1.

Machine learning method for spectral quench modelling and subsequent deconvolution of beta sources in contaminated liquid scintillation counting data. In collaboration with [GAU-Radioanalytical Laboratories](https://www.southampton.ac.uk/oes/research/facilities/gau.page) (GAU) at the University of Southampton.

[Interface Analysis Centre](https://www.bristol.ac.uk/physics/research/materials/research-areas/iac/), University of Bristol, UK.
